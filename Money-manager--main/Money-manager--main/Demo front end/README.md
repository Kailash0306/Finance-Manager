# Money Manager – Frontend

React frontend for the Money Manager backend (separate repo). Backend runs at `http://localhost:8081`.

## Setup

```bash
npm install
```

## Run

1. Start the backend (in its own repo) on port 8081.
2. Start the frontend:

```bash
npm run dev
```

App runs at **http://localhost:5173**. API calls are proxied to the backend.

## Build

```bash
npm run build
```

## Stack

- Vite, React 18, React Router 6
- **Tailwind CSS** for styling (dark theme)
